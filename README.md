# Zeeshan Raza — Portfolio

Personal portfolio website for Zeeshan Raza, featuring projects, product metrics, and leadership experience.

## Tech Stack
- **Framework:** React 19 + TanStack Start / TanStack Router + Vite
- **Styling:** Tailwind CSS v4 + Radix UI / shadcn/ui
- **Icons:** Lucide React
- **Deployment:** Vercel

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
